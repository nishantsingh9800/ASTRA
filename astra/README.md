# ASTRA 2.0

LOCAL-FIRST MULTIMODAL ACCESSIBILITY AI AGENT

## Overview
ASTRA 2.0 is a complete rebuild of the Astra agent, focusing on true local-first capabilities, strict verification of actions, and a robust accessibility-first design.

## Architecture
- **apps/**: Frontend applications (desktop, web, android)
- **services/**: Backend services and local AI agents
- **packages/**: Core logic, security, and context management
- **tests/**: Comprehensive testing suite
