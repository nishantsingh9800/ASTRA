# ASTRA 2.0

ASTRA 2.0 is a unified, multimodal, local-first personal AI assistant. It combines strict privacy, advanced accessibility features, multi-device hardware abstraction, and a rigorous autonomous self-improvement pipeline into a single, cohesive architecture.

## Features
- **Local-First & Offline Capable:** Runs speech-to-text, text-to-speech, and core orchestration locally on your Windows machine.
- **Multimodal Perception:** Real-time visual perception via laptop, phone, or smart glasses cameras. ASTRA enforces a strict "no-guess" policy for environmental understanding.
- **Multi-Device Handoff:** Seamlessly transition tasks from Windows to Android and Wearables via a centralized capability router.
- **Adaptive Accessibility:** Native support for sign language, AAC (Augmentative and Alternative Communication), switch devices, and cognitive profiles.
- **Emergency SOS:** Built-in sensor-fusion safety engine that detects falls/accidents and automatically escalates to emergency contacts.
- **Autonomous Agents:** A rigorous GOAL -> PLAN -> EXECUTE task loop utilizing specialized Research, Coding, and Productivity agents.
- **Managed Self-Improvement:** An automated software-engineering pipeline that observes failures, proposes code changes, builds them in an isolated workspace, and only deploys them if they pass a stringent benchmark and security health check.
